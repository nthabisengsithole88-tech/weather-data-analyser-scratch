 Weather Data Analyser (Scratch)
 
A simple interactive weather analyser built using **Scratch** as part of the **ALX Africa data science course**.
Project Overview
This project asks the user to enter the current temperature and uses conditional statements to determine whether the weather is **too hot**, **too cold**, or **perfect**.
The project demonstrates fundamental programming concepts including variables, user input, comparison operators, and decision-making using `if` and `if-else` statements.

How It Works
1. The program asks the user to enter the current temperature.
2. The input is stored in a variable called **Current temperature**.
3. The program evaluates the temperature:
   - Above **30°C** → Displays **"Too hot!"**
   - Below **20°C** → Displays **"Too cold!"**
   - Between **20°C and 30°C** → Displays **"Perfect temperature!"**
